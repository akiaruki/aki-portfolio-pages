Open-source components in the iOS app

Capacitor 8.4.3 and Cordova compatibility code

Connect the app's interface with native iOS features. Capacitor is provided under the MIT License; its Cordova-derived code carries Apache License 2.0 notices.

Capacitor source · Apache Cordova

LibRaw and its WebAssembly bindings

Support camera RAW decoding. The app bundles @colorhythm/libraw-wasm 1.1.1, LibRaw 0.22.1-Release, and typed-cstruct 0.10.2. The bindings and typed-cstruct use the MIT License. LibRaw is offered under LGPL 2.1 or CDDL 1.0 and includes additional attributed code.

Bindings source · Download LibRaw source and build materials · LibRaw source · typed-cstruct source

libheif-js 1.23.2 and libde265

Provide HEIF decoding support. The libheif WebAssembly build uses libde265 for HEVC decoding. These libraries are covered by LGPL 3.0 notices, with the accompanying GPL 3.0 text included in the full notices.

JavaScript package · Download HEIF source and build materials · WebAssembly build · libheif source · libde265 source

UTIF 3.1.0 and pako 1.0.11

Provide TIFF decoding and compression support. UTIF uses the MIT License. Pako includes MIT-licensed code and zlib-licensed compression code.

UTIF source · pako source

libwebp 1.6.0

Provides the native WebP encoder, integrated through the libwebp-Xcode package. Its BSD-style license and copyright notice are included in the full notices.

libwebp package and source
