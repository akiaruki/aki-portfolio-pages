Third-party source

Source code, license texts and build materials for Aki Studio's third-party image decoders and WebAssembly runtime.

The current iOS app retains its LibRaw and libheif/libde265 WebAssembly decoder resources. The LibRaw archive contains the MIT bindings and LibRaw source, including its LGPL 2.1 and CDDL 1.0 license alternatives and inherited component notices. The HEIF archive contains the bundled decoder's public source and build materials, including the LGPL 3.0 notices.

The Emscripten archive contains the core and system runtime sources from the compiler versions named by the preserved public build recipes: 4.0.15 for LibRaw and 3.1.61 for HEIF. Original compiler logs and a verified decoder rebuild are unavailable. Archives contain public third-party source and documented build modifications; unrelated test media, private application source and signing data are excluded. These online downloads do not modify the installed app or establish LGPL application recombination or installation compliance.
